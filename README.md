# skill-asana-organizer

![Category](https://img.shields.io/badge/category-Project%20Management-blue) ![Status](https://img.shields.io/badge/status-active-green) ![Author](https://img.shields.io/badge/author-Patrick%20Diamitani-purple)

Tired of Asana projects that are impossible to read at a glance? This skill takes any Asana project and cleans it up — rewrites task names so they actually make sense to stakeholders, proposes a logical section structure, and pushes all the changes back to Asana automatically.

## What It Does
- Fetches all tasks from any Asana project via URL
- Rewrites task names and descriptions for clear stakeholder communication
- Proposes an organized section structure (by status, team, priority, or custom)
- Applies all changes back to Asana — no copy-paste needed
- Preserves due dates, assignees, and custom fields

## How to Use
In Claude Code, say: `/asana-organizer` or describe what you want:
> "Organize my Asana project at [URL] for a leadership review"
> "Clean up this project and group tasks by status"

## Trigger Phrases
- "organize my Asana"
- "clean up this project"
- "rewrite tasks for leadership"
- "sort through my tasks"
- "group by status/team/priority"

## Setup
Requires an Asana Personal Access Token (PAT). Set it as `ASANA_PAT` in your environment or `.env` file. Get one at: https://app.asana.com/0/my-apps
